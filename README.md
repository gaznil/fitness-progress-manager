# Fitness Progress Manager

A planned mobile-first workout tracking app for OmniRush Frontier Buildathon 2026.

## Status

Planning stage. This repository currently contains documentation and repository setup only; no application features have been built.

## Planned features

- Workout tracking: log exercises, sets, repetitions, and weights in a mobile-first interface.
- Progress analytics: review workout history and visualize training progress over time.
- Free MCP connectivity: planned support for connecting compatible tools through the Model Context Protocol (MCP), with no app-imposed connection fee. Third-party services may have their own costs or limits.

## Development

OmniRush is the only generative AI to be used for buildathon application development. No application code is included in this initial setup. Technology choices and setup instructions will be documented when implementation begins.

RepFlow is only a working name and has not been trademark-cleared. The neutral repository name does not establish a final product name.

## Secrets and configuration

Never commit credentials, tokens, personal workout data, or local environment files. No environment variables are required at this stage; a placeholder-only `.env.example` can be added once configuration is defined.
